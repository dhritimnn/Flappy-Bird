# Flappy Bird - JS

Link: [flappybird-dh.vercel.app](https://flappybird-dh.vercel.app)

Flappy Bird is a popular mobile game released in 2013. The game follows a simple rule to tap on the
screen to guide a bird through the gaps of pipes. 

This project tries to resemble the logic and make a simple replica of the game Flappy Bird.

Language Used -  
`HTML` `CSS` `Javascript`

Assets -  
Fonts: `FlappyBirdyReguylar`  
Images: `background.png` `bird.png`  
Sounds: `bg.mp3` `jump.mp3` `over.mp3`

Approch:  
1. Configuring the positions of the graphic elements on a static frame using HTML CSS
2. Running the essential loops for a game session, i.e.- 
    - Horizontal loop of the background
    - Accelerated freefall of the bird
    - Score counting
3. Configuring the Jump Event
4. Configuring the Obstacle generating function
5. Adding the GameOver function and GameOver Screen
6. Additional touch-ups like storing high score at Localstorage, adding the sound effects etc.

Enjoy the game (:
